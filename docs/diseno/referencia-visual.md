# Referencia visual propuesta por el usuario

Referencia para el futuro cliente web/móvil: imágenes de búsqueda semántica, ficha e inicio aportadas en esta conversación. El logo elegido es la cuarta imagen: monograma K/N con cruz. Los nombres de comunidades, fotos, fuentes y datos de esos mockups son ilustrativos; no constituyen datos institucionales para cargar al backend.

Los controles de administración de los mockups deben seguir los permisos del servidor; una imagen de referencia no cambia las reglas de autorización del producto. La implementación actual de encuesta/perfil es de backend; esta paleta aún no se ha aplicado al cliente.
